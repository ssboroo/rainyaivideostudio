# RAINY Video Studio — үнийн бодлого ба сарын эрх
**Хянасан:** 2026-10-11 | **Зориулалт:** API-д суурилсан SaaS, Монгол хэрэглэгч

## 1. Чухал ялгаа

- **Higgsfield API** = USD prepaid, бодит хэрэглэсэн генерац бүрийн төлбөр, веб subscription-ийн Unlimited эрх ХАМААРАХГҮЙ.
- **RAINY сарын багц** = RAINY доторх кредит, Wire.mn-аар нэг удаа төлж хуанлийн 1 сар ашиглана. Энэ нь **автомат сунгалттай subscription БИШ**.
- Үнэ нь хугацаа, дэмжигдэх resolution, input frame/reference, sound, generation variant-аас хамаарна; баталгаажаагүй тохиргоог fail-closed болгоно.
- Хэрэглэгчийн кредит ашигласны дараа model provider дээр төлбөр бодогдоно; амжилтгүй генерацын кредит буцаалтын код байгааг анхаар. Бодит provider invoice-той нийлэхийг санхүүгийн тайлангаар шалгана.
- Хамгийн багадаа **сарын автомат сунгалтын хүсэлт, recurring invoice/mandate болон revoke flow** хэрэгтэй. Wire-ийн өнөөгийн ашиглаж буй hosted payment intent workflow нь нэг удаагийн төлбөр тул автомат debit нэмээгүй.

## 3. Эрсдэлийн тооцоолол

- Үнэ тооцох **дотоод төсвийн ханш**: 3,900 MNT/USD. Энэ нь Монголбанкны real-time FX-ийн ишлэл биш; худалдан авалтын бодит банкны ханштай байнга тулга.
- **API тарифаас үүсгэх RAINY кредит**: `ceil(providerUSD × 3,900 × 2.15 / (100,000/12,000))`.
- 2.15× гэдэг нь **үйлчилгээний өртөг дээрх 115% markup**, цэвэр ашгийн хувь биш.
- Сценарийн **FX +10%**, төлбөрийн шимтгэлийн **4% нөөц**, татварын **10% нөөц**, серверийн/архивын **7% нөөц**. Эдгээр нь төлөвлөлтийн таамаг: Wire-ийн гэрээний шимтгэл/НӨАТ-ын бүртгэл/бодит зардлыг баталгаажуулаагүй.
- Зорилтот **сценарийн contribution >=30%**. Энэ нь өгөгдсөн таамгийн хүрээнд л үнэн; бүх татвар, цалин, зар сурталчилгаа, cashback, chargeback, алдагдал, дата архивын цэвэр ашгийн баталгаа биш.
- Ямар ч `CREDIT_PACKAGES_JSON` override нь MNT/credit >=9.25 ба дээрх margin stress-ийг хангахгүй бол систем багцыг **татгалзана**.
- `RAVS_PRICING_HOLD=true`: үнийн гаргалт/шинэ генерацын хүсэлтийг түр хаах яаралтай хамгаалалт. Энэ нь **бэлэн хэрэглэгчийн кредитийг хүчингүй болгохгүй**, дууссан үүсгэлтийн статусыг хаахгүй.
- `/api/admin/pricing-economics`: админ-only багц, стресс тест, review хугацаа, жишиг API өртгийн тайлан. 30 хоног тутам API rates дахин шалгана.

## 5. Продакшнд зайлшгүй хийх нягтлан бодох ажиллагаа

1. Higgsfield USD balance, paid generation, refund болон output-ийн бодит provider billing event-ийг reconciliation тайланд тулга.
2. Сар бүрийн нийт `PAID` орлого ≠ цэвэр ашиг. Кредитийн үүрэг хариуцлага (unused prepaid liability), алдагдалтай chargeback, татвар, Wire шимтгэл, санхүүгийн шилжүүлгийн ханш, storage, серверийн төлбөрийг тусад нь хяна.
3. Үнийн албан баримт/processor нөхцөл өөрчлөгдвөл `RAVS_PRICING_HOLD=true` тавиад API model rates-ийг шинэчлэн тестэл. Баталгаагүй model-ийг автомат нэмэхгүй.
4. Төлбөрийг дахин авахгүйгээр бүтээлийн түүх, алдаа/буцаалт, идэвхтэй кредитийг хэрэглэгчид харуулах.
5. Жинхэнэ automatic monthly subscription хийх бол давтан төлбөрийн зөвшөөрөл, revoke, failed charge/cancellation, дээд дүн, webhook, ebarimt/татварын compliance тусад нь хэрэгжүүлэх; backend-д ганц cron нэмэх нь төлбөр татах эрх биш.

**Энэхүү баримт нь санхүүгийн шийдвэрийн сценарийн загвар, баталгаат өгөөж эсвэл татварын зөвлөгөө биш.**
